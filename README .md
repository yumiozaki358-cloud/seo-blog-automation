# SEOブログ記事自動生成システム

Googleスプレッドシートにキーワードを入力するだけで、Claude APIが下書き記事（タイトル・本文・メタディスクリプション）を生成し、WordPressに**下書きとして**投稿するGAS（Google Apps Script）ツールです。

> **本システムは記事を自動公開しません。** 生成された下書きは、必ず内容を確認・加筆修正のうえ、手動で公開してください。生成される記事は60〜70点程度の完成度を想定したたたき台です。

## できること

- スプレッドシートのキーワード・サブキーワードから、Claude APIで記事の下書き（タイトル／本文／メタディスクリプション）を生成
- 生成時、参考記事のトーン・構成パターンをプロンプトに反映
- WordPress REST API経由で、生成した記事を「下書き」としてWordPressに投稿（`status: 'draft'`固定。公開は行わない）
- キーワードごとのステータス管理（未生成→生成中→生成済み→投稿中→投稿済み／確認済み）
- WordPress未設定の場合は自動的に「確認モード」に切り替わり、実際には投稿せず送信予定のペイロードをログ出力するのみ

## 使用技術

| 技術 | 用途 |
|---|---|
| Google Apps Script (GAS) | 全体の制御・オーケストレーション |
| Google スプレッドシート | キーワード管理・生成結果の保存・操作UI |
| Claude API | 記事下書きの生成 |
| WordPress REST API | 下書き記事の投稿（Application Password認証） |

## スプレッドシートの列構成

1行目をヘッダーとして、以下の列を用意してください。

| 列 | 項目 |
|---|---|
| A | キーワード |
| B | サブキーワード |
| C | ステータス |
| D | タイトル |
| E | WordPress URL |
| F | 本文 |
| G | メタディスクリプション |

## セットアップ手順

### 1. コードの設置

1. Googleスプレッドシートを開き、「拡張機能」→「Apps Script」を開く
2. デフォルトのコードを削除し、`Code.gs`の内容を貼り付けて保存
3. スプレッドシートを再読み込みし、メニューに「記事生成」が表示されることを確認する

### 2. Claude APIキーの設定

1. [Anthropic Console](https://console.anthropic.com)で新規APIキーを発行し、コピーする
2. スプレッドシートのメニュー「記事生成」→「Claude APIキーを設定」からキーを貼り付けて保存する

APIキーはコードに直書きされず、GASの「スクリプトプロパティ」に安全に保存されます。

### 3. WordPress接続情報の設定（実投稿する場合のみ）

1. WordPressの管理画面 →「ユーザー」→「プロフィール」→「アプリケーションパスワード」で新規発行する
2. スプレッドシートのメニュー「記事生成」→「WordPress接続情報を設定」から、URL・ユーザー名・アプリケーションパスワードを設定する

この設定を行わない場合、システムは自動的に「確認モード」で動作し、実際の投稿は行わずペイロードをログ出力するのみになります。

> wordpress.com の無料プランはApplication Password／REST API書き込みに非対応です。実投稿を試す場合は、InstaWP等の無料WordPressサンドボックス、またはローカルWordPress＋ngrok/Cloudflare Tunnel等で公開URLを用意してください（GASはGoogleのサーバー上で動作するため、`localhost`には接続できません）。

## 使い方

1. スプレッドシートのA列にキーワード、B列にサブキーワードを入力する
2. 入力した行を選択し、メニュー「記事生成」→「選択行から記事を生成」を実行する
3. D・F・G列に生成結果（タイトル・本文・メタディスクリプション）が入る
4. 内容を確認し、問題なければ同じ行を選択して「選択行をWordPressへ下書き投稿」を実行する
5. WordPress管理画面で内容を最終確認・加筆修正のうえ、手動で公開する

## トラブルシューティング

| 症状 | 主な原因 | 対処 |
|---|---|---|
| Claude API呼び出しでエラー（HTTP 401/429/500など） | 401はAPIキー無効、429は利用量上限、500番台は一時的な障害 | 401はAPIキー再発行、429は時間を置いて再実行、500番台も同様 |
| Claudeの応答をJSONとして解釈できない | 出力が長くなりすぎて`max_tokens`到達で打ち切られた可能性 | 同じ行で再実行。繰り返す場合は`CLAUDE_CONFIG.MAX_TOKENS`を見直す |
| WordPress投稿時にエラー | URL・ユーザー名・アプリケーションパスワードの誤り、パスワード失効 | 「WordPress接続情報を設定」の内容を確認し、必要なら再発行 |
| メニュー「記事生成」が表示されない | スプレッドシートの読み込みタイミング、コード未保存 | スプレッドシートを再読み込み。それでも出ない場合はApps Script側でコード保存を確認 |
| 生成記事の文字数が少ない・内容が薄い | プロンプトの文字数指定が緩い | 再実行してみる。繰り返す場合はプロンプトの文字数条件を強化する |
| 「想定外のステータスで投稿されました」（重要） | 安全装置が作動：WordPress側の設定などにより下書き以外の状態で投稿されそうになった | 直後にWordPress管理画面で該当記事が誤って公開されていないか必ず確認する |

## 注意事項

- 生成された記事は必ず公開前にご確認ください（事実関係・法令名・数値等は特に）
- 本システムは記事を「下書き」として保存するのみで、自動公開は一切行いません
- 検索順位・流入数の向上を保証するものではありません
- Claude APIの利用料金は、利用者自身のAnthropicアカウントから直接発生します（本システムからの請求は発生しません）
